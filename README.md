# 💫 About Me:
I am a Full-Stack Developer with hands-on experience in web, mobile, backend, and hardware-integrated application development. My technical experience includes PHP, Laravel, MySQL, JavaScript, TypeScript, React, React Native, HTML, CSS, Bootstrap, Tailwind CSS, REST APIs, Git, GitHub, Node.js, NPM, Composer, Vite, Python, FastAPI, WebSockets, and Arduino-based development. I have worked on real-world applications involving authentication, dashboards, responsive UI, API integration, real-time communication, monitoring systems, and mobile application development, including building and troubleshooting Android APKs and production-oriented features such as crash reporting. Beyond software development, I have practical experience in robotics and IoT, including Arduino Uno, DC motors, L298N motor drivers, HC-05 Bluetooth communication, sensors, GPS, accelerometer and gyroscope data, camera streaming, and computer-vision-based vegetation analysis. One of my key projects is a six-wheel agricultural rover designed to assist farmers by collecting field information, identifying potential plant, soil, and insect-related problems, and providing useful recommendations through a combination of hardware, software, mobile interfaces, communication systems, and image analysis. I have also worked on a construction monitoring system focused on tracking government infrastructure projects, monitoring progress, and identifying issues. Alongside development, I have participated in hackathons and technical projects where I focused on solving practical problems and turning ideas into functional prototypes. My overall strength is combining different technologies to build complete solutions rather than working on isolated components, while continuously improving my skills in software architecture, debugging, system integration, and real-world product development.<br>
